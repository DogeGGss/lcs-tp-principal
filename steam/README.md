# Ficha de Steam — simulación académica

Página estática para presentar Project Riftwalker con una interfaz de tienda inspirada en Steam. No es un producto real en Steam, no está afiliada a Valve, no procesa compras ni solicita credenciales. El aviso permanece visible arriba; no se inventan reseñas de jugadores.

## Abrir

La URL publicada es `https://dogeggss.github.io/lcs-tp-principal/steam/`. Los archivos se sirven directamente por GitHub Pages, sin build ni dependencias externas.

Para una copia local, conservar `steam/` y la carpeta hermana `presentacion/media/` si se quiere reproducir el tráiler compartido. Galería, estilos y scripts están dentro de `steam/`.

## Interacciones

- Galería de seis piezas, flechas, teclado, ampliación y reproducción del tráiler.
- Lista de deseados, seguir e ignorar: guardado local con prefijo `rw-steam-demo:`; no afecta Steam.
- Selector entre ficha próxima y publicada: disponibilidad y precio identificados como simulados.
- Personajes con sus nombres actuales, retratos, roles y habilidades de Táctico.
- Búsqueda limitada al único juego de la simulación, menú, etiquetas y diálogos informativos.
- Descarga real y separada del launcher de GitHub. Siempre usa el enlace fijo de la release `launcher`, nunca `/releases/latest`, que corresponde al juego.

Contenido contrastado con la release estable v0.3.0 y las fichas del proyecto. No se afirma integración con Steam Cloud, logros de Steam, VAC, Workshop ni Steam Deck. Invasión no se presenta como modo terminado de esa estable; los requisitos sin medir figuran por determinar.

Las capturas de escenarios y el arte promocional se distinguen en la galería. Fuentes de assets en `assets/README-assets.txt`. La referencia visual fue una ficha pública de Steam consultada el 07/11/2026; el código de esta simulación es propio.
