# lcs-tp-principal 2

## Project Riftwalker · Launcher

**Launcher para jugadores** (se descarga una sola vez): [Riftwalker-Launcher.exe](https://github.com/DogeGGss/lcs-tp-principal/releases/download/launcher/Riftwalker-Launcher.exe). Las versiones del juego se instalan desde el launcher.

El launcher se desarrolla en `Launcher/`, separado del proyecto Unity. Detecta versiones nuevas,
descarga e instala actualizaciones, muestra notas del parche y permite probar releases experimentales.

**Equipo:** seguí [la guía para compilar, empaquetar y publicar versiones](Launcher/README.md).
El launcher tiene su propio release fijo (`launcher`); cada versión del juego es otro release, solo con el ZIP y `release.json`.

**Jugadores:** [instalación, aviso de Windows y desinstalación](Launcher/README.md#instalación-para-jugadores).

Diseño y documentación del juego: [LA PAGE](https://dogeggss.github.io/lcs-tp-principal/).
