Use case: logo-brand. Create one final standalone application icon for the original tactical multiplayer videogame PROJECT RIFTWALKER. Brand context: near-future tactical combat, railway infrastructure and a university campus; established brand orange #F29A38, near-black #0A0C11, off-white #F3F4F6. Design a distinctive bold geometric emblem: two heavy angular railway rails forming an abstract R / doorway, interrupted down the middle by a sharp negative-space dimensional rift. A few substantial shapes only; deliberate asymmetry, strong balanced silhouette, legible at 32 pixels. The orange emblem is inset on a near-black rounded-square tile with slightly chamfered corners and a fine subtle orange rim. Square composition, tile occupies about 88% of canvas, transparent outside tile. Flat precise vector-like graphic, exceptional professionally crafted esports/game identity, restrained depth only, no bloom, no tiny linework, no distressed texture. Absolutely no words, letters used as typography, captions, variations, mockup, scenery, watermark, or presentation board. Single large icon centered, actual transparent background. This icon will also anchor a matching game wordmark.
